# Ecological Understanding

Ecological Understanding is the educational and pedagogical domain
of the Ecological Interaction ecosystem.

Its purpose is to communicate ecological knowledge and methods through
courseware, teaching, tutorials and reusable learning resources.

## Scope

The domain includes:

- Ecological education and courseware.
- Surveilling Nature.
- Ecological Interactions Seminar.
- Teaching methodologies.
- Tutorials and learning resources.
- Distributed international educational programmes.
- Catalogues and links to independent course repositories as they become available.

Educational resources should support adaptation to different geographic,
ecological and institutional contexts while retaining clear methods,
source attribution and reproducible learning activities.

## Relationship to Ecological Information

Ecological Understanding develops teaching and learning resources.

Ecological Information develops research references, indicators,
classifications, datasets, metadata and knowledge bases. Understanding can use
and explain those resources without maintaining competing authoritative
copies.

Related projects are:

- EIRKB — Ecological Interaction Reference Knowledge Base.
- EII — Ecological Indicators Inventory.
- AMRKB — Agricultural Modes Reference Knowledge Base.

Permanent GitHub links can be added after these repositories are published.

## Current repository status

This repository remains at its original local path and retains its
complete historical Git record.

No independent course repositories are currently catalogued here.
The educational scope above describes the domain's intended work,
not a claim that those courses or resources are implemented in this repository.

The planned architecture places this existing repository in an
`_umbrella` directory beside future independent course repositories.
That relocation has not occurred.

## Historical research material

Earlier commits contain ecological-information research documents.
The historical narrative and V0 reference register now have authoritative
locations in EIRKB. Its current README is the revised successor to the
historical citation and knowledge architecture protocol.

[PROVENANCE.md](PROVENANCE.md) records original paths, commits,
checksums and current destinations.

Historical documents remain recoverable through Git history and the
verified pre-migration recovery snapshot. They should not be restored
as competing current authorities without an explicit decision.

## Development principles

- Preserve academic attribution and research provenance.
- Keep independently reusable courses and software within their own repositories.
- Document prerequisites, learning objectives, methods and limitations.
- Distinguish educational explanations from validated scientific claims.
- Record compatible software and dataset versions for reproducible activities.

Licensing, citation metadata and publication arrangements remain to be agreed.
