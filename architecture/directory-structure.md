# Proposed directory structure

Paths are relative to the existing ecological-understanding/ecological-understanding Git repository, not its outer organisational directory.

| Path | Responsibility |
|---|---|
| README.md | Public framework introduction and domain directory. |
| PROVENANCE.md | Existing historical provenance; preserve unchanged. |
| domains/EU-01-ecological-concepts-theory.md | Concepts and theory. |
| domains/EU-02-observation-monitoring.md | Observation and monitoring. |
| domains/EU-03-geographic-spatial-understanding.md | Geographic and spatial understanding. |
| domains/EU-04-ecological-indicators-inference.md | Indicators and inference. |
| domains/EU-05-systems-science-relationships.md | Systems science and relationships. |
| domains/EU-06-situated-cultural-knowledge.md | Situated and cultural knowledge. |
| domains/EU-07-computation-intelligence.md | Computation and intelligence. |
| domains/EU-08-synthesis-decision-making.md | Synthesis and decision-making. |
| domains/EU-09-design-technology-choice.md | Design and technology choice. |
| domains/EU-10-regenerative-systems-practice.md | Regenerative systems and practice. |
| architecture/overview.md | Courseware architecture and source responsibilities. |
| architecture/metadata.schema.json | Resource metadata validation rules. |
| architecture/component-template.md | Synthetic authoring template, excluded from catalogue. |
| architecture/interface-specification.md | Search, cards, grouping, filters and accessibility. |
| architecture/implementation-plan.md | Source integration, preview, validation and publication sequence. |
| inventory/README.md | Human-readable candidate inventory and evidence limits. |
| inventory/courseware-candidates.yaml | Structured candidate records, excluded from catalogue. |
| components/ | Future authored resource records; no completed modules in Phase 1. |
| programmes/ | Future Full Programme records with ordered, versioned references. |

Independent courses and software may remain in sibling repositories. No new repository creation is proposed. Website-side additions, in a later phase, are a publication manifest, scoped importer, navigation entries and optional catalogue assets. They are not included as active website changes here.
